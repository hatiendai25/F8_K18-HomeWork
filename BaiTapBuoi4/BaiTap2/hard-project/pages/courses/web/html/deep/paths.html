So sánh: Đường dẫn tuyệt đối (Absolute) và tương đối (Relative)

  1. Đường dẫn tuyệt đối (Absolute): Là đường dẫn đầy đủ, bắt đầu bằng giao thức (ví dụ: https://...). Dù đặt file ở đâu, trình duyệt vẫn có thể truy cập được.
  2. Đường dẫn tương đối (Relative): Là đường dẫn dựa trên vị trí của file hiện tại. Nếu di chuyển file HTML, đường dẫn có thể bị sai nếu cấu trúc thay đổi.
